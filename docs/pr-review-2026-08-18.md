## 附：处理流程说明

1. 部分 PR 与 `sync` 工作流（每 3 小时探测实时 star 并更新 `plugins/*.md`）产生的 star 值变更冲突，GitHub 服务器端 `update-branch` 亦报 422，故对简单的一行追加条目采用「本地应用到 main → 重新生成 `INDEX.md` / `README*.md` → 校验 → 提交推送 → 关闭 PR」的维护者常规流程。
2. 所有条目均先核验：仓库是否存在（404 检测）、star、是否归档、有无 README、README 是否声明 DSH。
3. 提交前运行 `node scripts/validate.mjs` 确认无重复收录、无格式错误。
